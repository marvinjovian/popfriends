Hitung HPP-mu tanpa pusing

Tiga kalkulator terpisah untuk tiga sektor usaha terbesar di Indonesia — masing-masing pakai cara hitung yang memang berbeda. Isi angkanya, langsung dapat HPP dan saran harga jual — lalu simpan ke Google Sheets-mu sendiri.

Sambungkan ke Google Sheets-mu

Belum tersambung
  1. Buat Google Sheet baru di Google Drive-mu.
  2. Buka menu Extensions → Apps Script.
  3. Hapus semua kode yang ada, lalu tempel kode di bawah ini (tombol salin di kanan atas).
  4. Klik Deploy → New deployment → pilih tipe Web app. Isi Execute as: Me, dan Who has access: Anyone. Klik Deploy.
  5. Salin Web app URL yang muncul, tempel di kotak di atas, lalu klik Simpan.
  6. Kembali ke Sheets-nya, refresh halaman — akan muncul menu baru 📊 Buku HPP. Klik 🎨 Setup Template Otomatis untuk memberi warna header otomatis.
  7. Untuk grafik tren HPP: blok kolom waktu dan kolom HPP → Insert → Chart.
function onOpen() {
  SpreadsheetApp.getUi()
    .createMenu('📊 Buku HPP')
    .addItem('🎨 Setup Template Otomatis', 'setupTemplate')
    .addToUi();
}

function setupTemplate() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sektor = {
    'Dagang': '#FFD9B8',
    'Kuliner': '#BFEFDA',
    'Manufaktur': '#C9DFFC'
  };
  Object.keys(sektor).forEach(function (nama) {
    var sheet = ss.getSheetByName(nama);
    if (!sheet) sheet = ss.insertSheet(nama);
    formatSheet(sheet, sektor[nama]);
  });
  SpreadsheetApp.getUi().alert(
    'Template siap! 3 tab (Dagang, Kuliner, Manufaktur) sudah diformat.\\n\\n' +
    'Untuk grafik tren HPP: blok kolom waktu + kolom HPP, lalu Insert > Chart.'
  );
}

function formatSheet(sheet, warna) {
  var lastCol = Math.max(sheet.getLastColumn(), 1);
  if (sheet.getLastRow() > 0) {
    var header = sheet.getRange(1, 1, 1, lastCol);
    header.setBackground(warna).setFontWeight('bold').setHorizontalAlignment('center');
  }
  sheet.setFrozenRows(1);
  sheet.autoResizeColumns(1, Math.max(lastCol, 10));
}

function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var ss = SpreadsheetApp.getActiveSpreadsheet();
    var sheetName = data.sektor || 'Riwayat';
    var sheet = ss.getSheetByName(sheetName);
    if (!sheet) sheet = ss.insertSheet(sheetName);
    if (sheet.getLastRow() === 0) sheet.appendRow(Object.keys(data));
    var headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0];
    var row = headers.map(function(h) { return data[h] !== undefined ? data[h] : ''; });
    sheet.appendRow(row);
    return ContentService.createTextOutput(JSON.stringify({status: 'ok'}))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({status: 'error', message: String(err)}))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  return ContentService.createTextOutput('Buku HPP Sheets Endpoint aktif ✅');
}
